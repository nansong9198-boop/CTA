## 与 CTA 体系的根本区别

| | CTA 体系 | 股票类体系（本草案） |
|---|---|---|
| 核心问题 | 股市跌时能不能赚钱 | 同样的股票敞口，管理人强不强 |
| 基准 | 无（绝对收益） | 自动识别（与沪深300/500/1000/创业板相关性最高者） |
| 关键指标 | 危机阿尔法、索提诺 | 信息比率、超额回撤、下行捕获比、alpha |
| 危机季要求 | 要赚钱 | 少跌 + 回撤修复快 |

alpha 10%、卡玛 10%、最长水下(逆) 10%

## 营销诚信度（2026-10-07 用户已拍板：纳入扣分项）

宣传口径 vs 实际净值数据的偏差，作为评分扣分项。典型案例：
龙旗X计划宣传"最大回撤 2.8%" vs 实际 -22.0%（偏差近 8 倍）。

## 绝对阈值线（2026-10-07 用户已拍板；回撤口径同日二次拍板修订）

**硬阈值**（任一项不达标 → 直接进"观察"档）：
- 费后年化 ≥ 10%
- **前5大回撤均值 ≥ -20%**（2026-10-07 二次拍板修订：回撤不能只看单次最大值，
  单次回撤只是尾部事件，风控能力看分布。前5大回撤 = 净值序列中独立回撤 episode
  （峰值→谷底）按深度排序取前 5 取平均；episode 不足 5 个时用实际数量并标注低置信度；
  当前仍水下的未修复 episode 计入均值并单独标注——未修复意味着损失是现实的而非历史的）
- 夏普 ≥ 1.0
- 信息比率 ≥ 0.5

**回撤形态展示指标**（每只产品必算，2026-10-07 新增）：
- 前5大回撤均值、回撤集中度（最大回撤÷前5大回撤均值，≈1 说明深度回撤是常态、
  风控系统性差；明显>1 说明是单次尾部事件）、深度回撤次数（谷底跌超 -10% 的
  独立 episode 数）、实质回撤（<-5%）平均修复时间（周）

**软指标**（扣分但不一票否决，用户 2026-10-07 拍板）：
- 最长水下 ≤ 12 个月（国源拾金3号 824 天仅扣分，不否决）
