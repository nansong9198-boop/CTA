- 费率: 管理费1.5%/年 / 业绩报酬20% / 锁定期无锁定期
- 回撤形态: 前5大回撤均值-11.9%（41个独立episode） / 回撤集中度1.40 / 深度回撤(谷底<-10%)次数4 / 实质回撤(<-5%)平均修复15周

- 费率: 管理费2%/年 / 业绩报酬20% / 锁定期3个月
