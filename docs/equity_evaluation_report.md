### 结论：国源水下824天是个案还是行业现象

- 同业（7只有数据）窗口最大回撤中位数 -46.4%，水下天数中位数 963 天，2024-04前修复创新高 1/7；国源窗口最大回撤 -16.7%，水下 824 天，已于2024-04-03修复
- 同业普遍回撤更深、修复更晚 → 国源的防守在同业中偏上，水下长主要是行业贝塔问题
- 与用户12个月水下容忍度（软指标）的关系: 824天≈27个月，远超容忍度；即便属行业现象，该窗口主观股多普遍水下963天量级，说明'主观股多+长水下'是此类资产的系统性特征，配置比例应据此控制
