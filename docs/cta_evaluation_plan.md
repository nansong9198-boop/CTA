# CTA 私募筛选评估方案

> **工作目录：`~/cta_eval/`**，按 `scripts/`（脚本）、`docs/`（文档）、`data/`（数据）三层组织
> 适用场景：蛋卷基金「管理期货(CTA)」私募货架产品筛选
> 投资者画像：合格投资者、可投 100 万+、进取型、持有期 3 年以上
> 创建日期：2026-10-06
> 最近更新：2026-10-06 —— 新增两只新产品评估结论（悬铃列入观察名单、千象商品指增B双门槛出局）；股票敞口门槛升级为四指数取最大（新增剔除均成增强5号、文谛量化16号）；推荐层增加绝对阈值线（夏普>1.0、回撤>-15%、危机胜率≥60%）；危机指标设最小样本门槛（<4个危机季度不计分）；迁移至独立目录

## 一、指标评估结论

| 指标 | 处理 | 理由 |
|---|---|---|
| 索提诺（下行偏差） | **核心，权重 25%** | 只惩罚下行波动，直接对应"下行偏差小"的诉求 |
| 危机阿尔法 | **核心，权重 20%** | 股市下跌季度的收益与胜率，买 CTA 的目的本身（危机均季收益 10% + 危机胜率 10%） |
| 回撤形态 | **权重 15%** | 最长水下时长（10%）+ 最长连亏季度数（5%），比回撤深度更影响持有体验 |
| 新高占比 | **权重 10%** | 回撤修复速度的度量，不依赖单一极端事件 |
| 盈亏比 | **权重 10%** | 平均盈利季 / 平均亏损季，替代单独的胜率 |
| 夏普 | 降权至 10% | 惩罚上涨波动，对右偏的 CTA 不公平 |
| 卡玛 | 降权至 5% | 依赖单一最深回撤事件；季度数据下回撤被低估 1.5~2 倍，卡玛虚高 |
| 胜率 | 降权至 5% | 单独追求会引向套利型策略（平时小赚一次大亏），须与盈亏比配对 |
| 尾部效应（偏度/ES） | 不参与评分 | 10~30 个季度的样本算偏度没有统计意义，改用回撤形态 + 最深单季定性判断 |

## 二、三层筛选结构

### 第一层：硬性门槛（不配权重，直接过滤）

- 剔除假 CTA：名称含「中性」「指数」「指增」的产品（如黑翼中性多策略、千象指增、南华商品指数）——它们在股市下跌时无法提供危机保护
- **剔除股票敞口过高的产品**：与沪深300/中证500/中证1000/创业板指**任一指数**季度收益相关系数 ≥ 0.30 的剔除（S3 整改：多指数取最大值，可捕捉小盘/微盘敞口）。**口径决策（2026-10-07 用户拍板）**：曾评估改用"下行相关性"（只算股指下跌季度，跟涨不罚）——因诺等产品的相关性主要来自跟涨季；用户选择**不改**，维持全周期口径，宁保守不误纳
- 成立 <3 年的产品：可参与评分但吃可靠性折扣（见第三层）
- **管理人（公司）门槛**（2026-10-07）：管理人成立不足 5 年、或管理规模 <10 亿元的，旗下产品直接剔除；规模无公开数据（如信达期货资管）不剔除但在报告风险点标记"未核实"。数据存于 `data/manager_info.json`（公司全名 → 成立年份/规模/来源 URL，2026-10-07 联网调研自中基协/私募排排网/年报等，规模矛盾时取保守下限）；货架 keeper 字段截断或缺失时用 `_symbol_override` 按基金代码映射。管理人有监管处罚记录的（均成警示函+暂停备案、博孚利处罚、富善走私处罚）在报告风险点单独标注
- **任职区间过滤**（2026-10-07，借鉴 who-is-the-best-manager 的 in_tenure 口径）：`data/pm_tenure.json` 提供某产品现任基金经理任职起点（`{"代码": {"pm": "姓名", "pm_start": "YYYY-MM-DD"}}`）时，仅统计其任职后的季度；任职以来不足 4 个季度的剔除。前任经理的历史业绩不计入——我们买的是现任的管理能力。当前文件为空占位，待补排排网/协会备案的任职数据

### 高适配层绝对阈值线（F3 整改，2026-10-06；2026-10-07 起分层改称适配度）

分数达高适配线（≥0.70）还须同时满足：**夏普 > 1.0、季度口径回撤 > -15%、危机胜率 ≥ 60%（危机样本达标时）**，否则降级备选——避免纯相对排名失真。

### 第二层：加权评分

各指标先转为横截面分位数（0~1，越大越好），再加权：

```
score = 0.25×索提诺 + 0.10×危机均季收益 + 0.10×危机胜率
      + 0.10×水下时长(逆) + 0.05×最长连亏(逆)
      + 0.10×新高占比 + 0.10×盈亏比
      + 0.10×夏普 + 0.05×卡玛 + 0.05×胜率
```

### 第三层：可靠性折扣

```
reliability = min(1, 季度数 / 24)        # 6 年(24 季)满信度
final_score = score × reliability + 0.5 × (1 - reliability)
```

短样本基金的分数向中位数收缩，防止"2 年新星"靠运气碾压"9 年老将"。

## 三、数据口径与已知缺陷

1. **数据源**：蛋卷货架接口的逐季度收益序列（`fund_index_info.data_list`），序列末项 = 2026Q3（已与各基金成立日期交叉验证）。**2026-10-07 修复：`data_list` 实为最新季度在前（倒序），此前按正序对齐导致回撤形态/新高占比/水下时长/连亏及危机阿尔法、股指相关性的季度标签全部错位；已反转还原（`analyze_cta.py`/`audit_cta.py`），并经排排网净值逐季核对确认（如宏锡量化CTA7号 38 个季度逐一匹配）**
2. **季度频率缺陷**：看不到季度内回撤，最大回撤/卡玛被系统性低估。已用排排网周/日频数据实测（2026-10-07，F1）：全池低估中位数 1.6 倍，低波动头部产品 2.7~4.1 倍，详见 `docs/cross_validation.md`
3. **分红/份额口径风险（2026-10-07 发现）**：蛋卷季度序列与排排网复权净值存在口径不一致的产品——远澜银杏1号（37 季 0 匹配，排排网 `distribute_method=现金分红`，蛋卷疑为除权单位净值口径）、均成CTA增强25号1期（0/13，现金分红且有分红变更记录）、因诺CTA2号B（仅 3/16 匹配，分红再投资+分红变更，疑为 B 类份额费率/计提差异）。**季度口径仅作辅助参考，最终结论以排排网周频口径（`docs/simuwang_weekly_report.md`）为准**
4. **危机阿尔法基准**：沪深300 + 中证500 + 中证1000 + 创业板指四指数并集，"危机季度" = 任一指数当季收益 < -3%（严格口径，2016Q1~2026Q3 共 15 个，含 2026Q3 大跌季）。数据源：沪深300 用东财全历史（已验证 2024Q3=+16.1% 正确），中证500/创业板用新浪日K聚合（覆盖 2022Q4 起，已验证 2024Q1 中证500=-2.6% 正确）；2022Q4 之前的小盘股单独下跌场景（如 2017 创业板）未覆盖。**注意：腾讯 ifzq 指数行情数据错位一个月（2024 年 9 月大涨被记到 10 月），已弃用**
5. **同周期对比**：另设最近 8 个季度（约 2 年）公共窗口口径，用于检查业绩时效性（策略是否钝化）
6. **数据剔除**：`fund_point` 字段 = 新基金周度净值点（口径不同），对应产品（如悬铃尊享稳健CTA5号，2026-03 成立）不参与季度口径评分；季度数 <4 的产品自动剔除

### 审计发现（2026-10-06，`audit_cta.py` 复核）

- 排序计算已逐项复核，无 bug；因诺 vs 量派的位次差异完全来自可靠性折扣（设计使然）
- 8 只基金季度数比成立日期推导少 1（首个不完整季度不计入，良性）
- 远澜云杉2号存在约 7 个季度的数据缺口（2017-08 成立但序列仅从 2019Q2 开始）
- 7 只基金各含 1 个 0.00% 季度，疑似缺失填充值，对胜率影响约 3 个百分点且不改变相对排序
- 9 只基金无成立日期，年数按季度数反推（信度系数不依赖成立日期，无影响）
- 季度口径回撤/卡玛经排排网同窗口数据验证低估 2~4 倍，绝对值不可直接用，相对排序可参考
- 审计明细全表：`danjuan_cta_full_audit.csv`

## 七、复现方式

目录结构（2026-10-06 起）：
```
~/cta_eval/
├── scripts/   extract_danjuan_cta.py(拉数据) / analyze_cta.py(评估+生成报告) / audit_cta.py(审计复核)
├── docs/      cta_evaluation_plan.md(方案) / cta_evaluation_review.md(审查) / danjuan_cta_report.md(自动报告)

```

```bash
cd ~/cta_eval
python3 scripts/extract_danjuan_cta.py '<整段Cookie>'   # 1. 拉取货架数据(Cookie 过期需重新提供)
python3 scripts/analyze_cta.py                          # 2. 评估并自动生成 docs/danjuan_cta_report.md
python3 scripts/audit_cta.py                            # 3. 独立审计复核
python3 scripts/fetch_simuwang.py                       # 4. 抓排排网高频数据(Cookie 存 data/simuwang_cookie.txt, 已gitignore)
python3 scripts/compare_simuwang.py                     # 5. F1交叉验证, 生成 docs/cross_validation.md
```
